# 二上语文默写小纸条 - 平台使用设计逻辑

## 概述

基于《二上语文全册每日10分钟默写小纸条80天》设计的默写练习模块。
共 8 个单元，每单元含 4-5 篇课文 + 语文园地 + 单元复习，每篇课文分 (一)(二) 两部分，共 80 份练习。

## 数据结构

### 层级关系

```
单元 (Unit)
  └── 课文/园地 (Lesson)  ← 同名归为一组，如"小蛤蟆找妈妈"包含(一)(二)
      └── 部分 (Part)  ← (一) 或 (二)
          └── 大题 (Section)  ← 一、二、三...
              └── 小题 (Question)  ← 每个填空/注音/选择
```

## 题型设计

### 1. 看拼音写词语 (`pinyin_to_word`)

- **展示**: 拼音 + 输入框
- **考察**: 写字表、词语表
- **作答方式**: 文本输入（手写或键盘）
- **匹配**: 精确匹配答案，忽略首尾空格
- **示例**:
  - 拼音: `kan jian` -> 答案: `看见`
  - 拼音: `na li` -> 答案: `哪里`

### 2. 给加点字注音 (`char_to_pinyin`)

- **展示**: 词语 + 输入框（标注加点字）
- **考察**: 识字表
- **作答方式**: 拼音输入（声调可选）
- **匹配**: 去除声调后匹配，或带声调精确匹配
- **示例**:
  - 词语: `池塘(  )` -> 答案: `tang`
  - 词语: `大脑(  )` -> 答案: `nao`

### 3. 根据语境看拼音写字词 (`context_fill`)

- **展示**: 句子 + 拼音提示 + 填空
- **考察**: 写字表、词语表（语境运用）
- **作答方式**: 文本输入
- **匹配**: 精确匹配
- **示例**:
  - `小猫咪的yan jing(  )亮晶晶的` -> 答案: `眼睛`

### 4. 形近字选择填空 (`similar_char`)

- **展示**: 句子 + 选项括号 `[哪 那]` + 填空
- **考察**: 形近字辨析
- **作答方式**: 点击选择（按钮）
- **匹配**: 选项值匹配
- **示例**:
  - `[哪 那] (  )里都没有山(  )边的景色美。` -> 答案: `哪, 那`

### 5. 画正确读音 (`select_pronunciation`)

- **展示**: 词语 + 多个读音选项
- **考察**: 多音字、识字
- **作答方式**: 点击选择
- **匹配**: 选项值匹配
- **示例**:
  - `教书` -> 选项: `jiao / jiao(教)` -> 答案: `jiao`

### 6. 词语补充 (`complete_phrase`)

- **展示**: 部分词语 + 填空
- **考察**: 词语积累
- **作答方式**: 文本输入
- **匹配**: 精确匹配
- **示例**:
  - `冰天(  )地` -> 答案: `雪`

### 7. 近义词 (`synonym`)

- **展示**: 词语 + 填空
- **考察**: 词语理解
- **作答方式**: 文本输入
- **匹配**: 精确匹配（支持多个可接受答案）
- **示例**:
  - `茂密 -> (  )` -> 答案: `茂盛`

## 答案匹配逻辑

### 答案存储

答案独立存储，不随题目展示，学生作答时不可见。批改时统一调取匹配。

```json
{
  "answers": {
    "unit_1_xiama_1": {
      "section_1": ["看见", "哪里", "头顶", "雪白", "宽大", "良贞", "胖子", "屋肤", "中求"],
      "section_2": ["tang", "nao", "hui", "jiao", "pbu", "yfng", "gui", "pi", "gi"]
    }
  }
}
```

### 匹配规则

| 题型 | 匹配方式 | 容错 |
|------|----------|------|
| 看拼音写词语 | 精确匹配 | 忽略首尾空格、全半角统一 |
| 给加点字注音 | 去声调匹配 | 支持带/不带声调 |
| 语境填空 | 精确匹配 | 忽略首尾空格 |
| 形近字选择 | 选项值匹配 | 无容错 |
| 画读音 | 选项值匹配 | 无容错 |
| 词语补充 | 精确匹配 | 忽略首尾空格 |
| 近义词 | 多答案匹配 | 支持多个可接受答案 |

### 批改流程

```
1. 学生完成全部题目 -> 提交
2. 系统逐题匹配答案
   - 正确: 标绿 + 对号
   - 错误: 标红 + 叉号 + 显示正确答案
   - 未填: 标灰 + 圈号
3. 计算得分（每题分值 = 100 / 总题数）
4. 展示批改结果
   - 总分
   - 正确/错误/未填 数量
   - 逐题展示（题目 + 学生答案 + 正确答案 + 对错标记）
5. 记录本次成绩到 appData
```

## 平台 UI 设计

### 导航层级

```
语文殿堂
  └── 同步默写单（已存在）
      ├── 第一单元
      │   ├── 小蛤蟆找妈妈
      │   │   ├── (一)  ← 点击进入练习
      │   │   └── (二)
      │   ├── 我是什么
      │   ├── 植物妈妈有办法
      │   ├── 语文园地一
      │   └── 单元复习默写
      ├── 第二单元
      └── ... 第八单元
```

### 练习页面

1. **题目区**: 按大题分块展示，每题有输入框/选择按钮
2. **进度条**: 顶部显示 已完成/总题数
3. **提交按钮**: 全部完成后可提交批改
4. **批改结果**: 逐题展示对错，错题显示正确答案
